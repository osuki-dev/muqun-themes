# Silver on the Neva

Icy cyan and cobalt surfaces pair with fine silver engraving of winter embankments. The faceted back arrow, curved folded-letter send mark and wrought-iron attachment loop echo ice and railings. Template glyphs adapt to both palettes. Separate day/night portrait and wide scenes, a transparent lantern vignette and a dedicated gallery cover are included. Home identity stays default.

CLI 1.7.1 validate, contrast and check --sources pass. This theme has nine assets, no warnings and packs to 2.26 MiB. UI and terminal opacity floors are 87% and 83%, below authored values of 92% and 94%. The inherited One Piece source retains six existing size warnings.

Artwork and glyph silhouettes were inspected locally. The preview server runs on port 4177. Actual browser review and an individual PR remain pending; browser access previously failed administrator-policy verification and startup alone is not a visual pass.
