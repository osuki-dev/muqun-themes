# Silver on the Neva

Icy cyan and cobalt surfaces pair with fine silver engraving of winter embankments. The faceted back arrow, curved folded-letter send mark and wrought-iron attachment loop echo ice and railings. Template glyphs adapt to both palettes. Separate day/night portrait and wide scenes, a transparent lantern vignette and a dedicated gallery cover are included. Home identity stays default.

## Editorial Home

Editorial uses the cover header with a bare utility row. Its 2:1 transparent foreground preserves the approved bridge-and-ice Classic hero, shifted toward the right so the native title stays legible. The original square hero, startup wallpaper, default identity, palette, and compact/regular mode choices remain unchanged.

CLI 1.9.0 validation, contrast, package round trip, packaged validation, and the 60-theme source check pass. This theme has 11 assets and packs to 2.56 MiB. Shared interface and terminal opacity floors remain 87% and 83%, below authored values of 92% and 94%. The CLI warns that its published build does not yet read the app's new `homePresentation` field; the field is intentionally retained for the matching app release.

Artwork and glyph silhouettes were inspected locally, including the transparent 1024 × 512 Editorial composition. Earlier browser review limitations remain; this validation does not claim a native device import test.
