# Artwork credits

The four character/environment PNGs are original OpenAI built-in imagegen artwork directed by Muqun Theme Collection on 2026-10-16. Only the original theme-owned character and light environment were used as references. No stock image, third-party character, external photograph, font, or logo is included. License: CC-BY-4.0. Source: the built-in generation session, with exact prompts and reference roles in [PROMPTS.md](PROMPTS.md); no public generation URL exists.

- `assets/character.png`: complete standalone character with preserved transparency, reused for launch and empty states.
- `assets/home-safe.png`: separately spaced Home version preserving the complete character with larger control/fade margins.
- `assets/environment-light.png` and `assets/environment-dark.png`: continuous character-free environments; night companion preserves the same scene.
- `assets/preview.png`: repository artwork/palette compositor output, light left and dark right, without simulated App controls.

All eight `assets/icon-*.png` glyphs are unmodified CC-BY-4.0 drawings by Muqun theme author, reused from [Pine & Parchment](https://github.com/osuki-dev/muqun-themes/tree/main/src/pine-and-parchment). They use template tint. Parameters is an independent two-rail adjustment glyph with leaf handles; settings remains a separate gear. Source directions: back left, send up-right, Home arrow right.
