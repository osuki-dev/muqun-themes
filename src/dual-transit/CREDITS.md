Original illustrations generated for Muqun using OpenAI image generation on 2026-09-23. New adult courier characters; no Cover Courier character assets reused. The creator dedicates the included illustrations and original seven semantic raster glyphs under CC0-1.0.

Home uses dedicated transparent upper-body art. Launch uses separate complete full-body art with contain fitting. Wallpapers contain no people; no foreground is duplicated. Gallery preview is composed from these same assets.

Dust and embers require the updated Muqun 3.0.0 build with the ambient-effect extension; older builds do not support these enum values. Existing Classic and Editorial layouts own all geometry.
