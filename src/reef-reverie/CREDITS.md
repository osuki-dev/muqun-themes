# Reef Reverie artwork credits

All character and wallpaper artwork was created specifically for Muqun with OpenAI image generation on 2026-09-26. These are original characters and environments, not adaptations of a named franchise. Source: OpenAI image generation tool in this authoring session (no external source URL). The contributor dedicates the resulting theme assets under CC0-1.0.

- `home-light.webp`: original close portrait of an adult professional diver and manta, transparent background; closed technical wetsuit.
- `home-dark.webp`: independently generated night-lighting variation of the same portrait, transparent background.
- `launch-light.webp`, `launch-dark.webp`: independent complete full-body diver and manta composition, transparent background; shared across modes because its balanced lighting reads on both backgrounds.
- `wallpaper-light.webp`: original sunlit coral cathedral, vivid aquamarine and coral.
- `wallpaper-dark.webp`: independent black-green bioluminescent coral cathedral.
- `icon-*.png`: seven original Muqun nautical geometry glyphs authored as vector paths and rasterized; template rendering follows theme colors. The Home arrow points up-right.
- `preview.png`: composition of this theme's own assets and palette.

Generation prompts requested original premium Japanese anime art, fully contained subject silhouettes, genuine alpha for character artwork, separate underwater cathedral backgrounds, and no text or logos. Home and launch are intentionally different compositions.
