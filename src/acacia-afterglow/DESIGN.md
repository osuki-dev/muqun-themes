# Acacia Afterglow

Kenyan acacia grasslands interpreted through reduction-linocut texture. Broad umbrella canopies, open golden grass and dusty mauve hills define the setting. The small elephant is a distant accent, leaving the interface calm.

Light mode uses sun-warmed gold paper, burnt umber text and deep ochre actions. Dark mode uses plum-brown charcoal, straw-gold actions and mauve borders. Semantic colors remain distinct from the artwork. UI and terminal planes use 96% opacity for reading.

Four separately composed wallpapers cover compact and regular layouts in light and dark modes. An isolated acacia-and-pod illustration serves empty states. The back glyph is a leafy twig arrow; send is a swept bird; attach is a curved seed-pod paperclip. Template alpha lets the palette tint all three. Default Muqun identity is preserved.

Editorial Home uses the cover header with normal theme-colored toolbar surfaces and a dedicated 2:1 acacia-and-giraffe foreground. The same contained asset is explicit for light and dark, compact and regular widths because its cream-and-cocoa edge work remains legible on both palettes. Classic keeps the original square giraffe hero and its startup behavior unchanged.

The gallery preview is a 1024 × 640 diptych of the theme's own artwork, light on the left and dark on the right.

## Validation

CLI 1.8.0 source validation, package round trip and full source check with required previews pass. This theme has no warnings. Shared contrast floors: interface 88%, terminal 85%. Artwork, transparency and template glyphs at 17px and 34px were visually reviewed.

The CLI preview server was started. The browser surface became unavailable before the complete light/dark phone/tablet Home, Conversation and Terminal review; that rendered review remains pending.

## Toolbar surfaces

Toolbar controls use the normal theme surface. This theme does not force a transparent or specially translucent toolbar; readers can adjust surface opacity in the app.
