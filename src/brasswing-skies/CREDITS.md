# Brasswing Skies artwork

All six character and airship harbor illustrations were generated specifically for this original Muqun theme with OpenAI image generation in September 2026. No franchise character, third-party photograph, or external reference artwork was used. Source: this authoring session (no public URL). Released with this theme under CC0-1.0.

- `assets/home-light.webp` and `assets/home-dark.webp`: original Western hand-drawn raccoon aviator portrait and independently generated night-lighting variant.
- `assets/launch-light.webp` and `assets/launch-dark.webp`: independent complete full-body launch illustrations, with travel suitcase and compass, consistent jacket, goggles and scarf. Actual transparent alpha is preserved.
- `assets/wallpaper-light.webp` and `assets/wallpaper-dark.webp`: independent daylight and lantern-lit monumental brass airship harbor paintings.
- `assets/icon-*.png`: seven original airframe-inspired geometric glyphs, authored as vectors and rasterized to transparent template PNG; CC0-1.0.
- `assets/preview.png`: composed from this theme's own artwork and palette.

Supported glyphs: chrome.back, chrome.send, chrome.attach, chrome.create, chrome.scan, chrome.settings, home.arrow. The Home arrow points up-right, as declared by iconDirections. All other App glyphs remain built in.
