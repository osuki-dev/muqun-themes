# Image prompts

All raster artwork was generated with OpenAI image generation and finished for Muqun.

## Background — Light

Create a quiet kissaten after rainfall in a refined editorial illustration style. Use coffee amber, bottle green, aged cream. Wide 2:1 composition, complete scene, no text, no logos, no cropped focal objects.

## Background — Dark

Reimagine the same visual world at night with independently painted lighting, deeper values, preserved detail, and restrained luminous accents. Wide 2:1 composition, no text or logos.

## Hero — Light

Create a transparent siphon coffee service as a complete centered object, transparent background, no cast-off cropping, no words, generous padding, app-icon clarity.

## Hero — Dark

Create a separately lit night variant of a transparent siphon coffee service, transparent background, complete silhouette, no words, generous padding.

## Current artwork mapping

Generated assets above retain their original filenames and provenance. The current manifest resolves a single `home.artwork` in both Classic and Editorial; `launch.artwork`, when present, is a separate startup composition. No additional image generation was performed for this slot migration.
