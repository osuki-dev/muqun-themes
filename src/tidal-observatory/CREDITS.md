# Tidal Observatory artwork

Original artwork created for Muqun with OpenAI's built-in image generation tool on September 26, 2026. The adult ocean researcher, hydrophone instrument, observatory and luminous sky whale are original fictional designs. No franchise characters, external reference artwork or third-party photographs were used. Released under CC0-1.0 to the extent permitted by applicable rights.

## Included artwork

- `figure.webp`, `figure-dark.webp`: Independent Home portraits with complete head, hair, arms, scarf and instrument. The lower jacket deliberately dissolves into transparent watercolor flecks. This soft edge is intentional; there is no straight rectangular crop. The night variant changes illumination rather than identity.
- `launch.webp`, `launch-dark.webp`: Independently generated complete launch vignettes. The complete researcher, boots, instrument, observation platform and sky whale are contained inside the canvas. The space outside and between the figures is truly transparent; no opaque sky panel is packaged. Night illumination uses sea-glass mint and amber.
- `wallpaper-light.webp`, `wallpaper-dark.webp`: Separate character-free ocean observatory environments, with pearl cumulus daylight and evergreen aurora night. These assets own the full environmental background.
- `preview.png`: 1024 by 640 browser-rendered gallery composition using this theme's own light and dark assets.
- `icon-*.png`: Original vector-authored semantic glyphs rasterized to 96 by 96 transparent PNG. Rounded instrument-like forms retain recognizable back, send, attachment, create, scan, settings and directional-arrow meanings. The arrow's original direction is up-right. Template tinting follows the current palette.

## Generation prompts

Home: Original adult Japanese anime marine researcher, short windswept charcoal hair, ivory and sea-glass field jacket, coral scarf, brass hydrophone, expressive face gazing upward, sophisticated hand-painted cel animation. Prominent portrait with complete head and arms, right-oriented composition and utility-control negative space. Genuine transparent alpha. Deliberate fine watercolor dissolution at the lower jacket only. No text, logos, scenery panel or franchise imitation.

Launch: The same adult researcher stands fully visible on a small observation platform, looking up at a complete luminous pearl sky whale curving above her. Equipment, boots, fins and tail stay inside the canvas. Independent cinematic vignette, delicate cloud/water wisps, genuine transparency outside and between subjects, no rectangular background. Night variation keeps the composition and changes lighting to sea-glass mint and warm amber.

Wallpaper: A vast emerald sea, monumental pearl cumulus clouds and an ivory oceanographic observatory with coral rails, grasses and a lighthouse. A distant sky whale suggests scale. Sophisticated painted animation environment, no foreground person, no lettering. Day uses pearl and warm sun; night uses charcoal, evergreen, mint aurora and amber windows rather than navy blue.

## Technical presentation

Compact and regular bindings are explicit. Home and launch assets use contain fitting. Launch is never substituted with the Home portrait. Solid UI planes preserve readability and user-controlled opacity. The restrained particles use the App's existing bounded effect engine; this package includes no animation code or runtime scripts.

The seven currently supported semantic icon slots are customized. Built-in OpenCode, Sessions and Terminal glyphs are not claimed to be replaceable unless the App/CLI contract adds corresponding slots. Actual website previews cover both layouts, both modes and phone/tablet; native App installation is a separate test and is not claimed by these assets.
