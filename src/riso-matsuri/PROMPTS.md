# Image prompts

All raster artwork was generated with OpenAI image generation and finished for Muqun.

## Background — Light

Create a two-ink summer matsuri print in a refined editorial illustration style. Use vermilion, ultramarine, uncoated paper. Wide 2:1 composition, complete scene, no text, no logos, no cropped focal objects.

## Background — Dark

Reimagine the same visual world at night with independently painted lighting, deeper values, preserved detail, and restrained luminous accents. Wide 2:1 composition, no text or logos.

## Hero — Light

Create a transparent festival emblem as a complete centered object, transparent background, no cast-off cropping, no words, generous padding, app-icon clarity.

## Hero — Dark

Create a separately lit night variant of a transparent festival emblem, transparent background, complete silhouette, no words, generous padding.
