# Spore Protocol design, version 1.2.0

A modern 2D anime botanical field explorer, with natural mushrooms along a sparse lichen path. This replaces the old miniature specimen pile. The independent centered startup explorer has no scenery and preserves transparent alpha.

Editorial uses the cover composition and short native title Spore, while metadata retains Spore Protocol. Home artwork has a 768x560 transparent canvas with generous left title space and a complete explorer on the right. Compact and regular repeat contain fit, opacity and focal point. Classic intentional lower-third overlap is accepted; no compact shrink canvas is used.

The light/dark lichen, ivory, ink and periwinkle palettes, all seven recognizable native template glyphs, and eleven purposeful native artwork roles are retained. Wallpapers never repeat the foreground subject. Chrome surface patterns remain sparse and low opacity.

The split preview is composed from actual final artwork and palette and is not a native screenshot. CLI validation, contrast and package round-trip are run after each final update. Native Editorial phone/tablet title and control balance require the new explorer package; previous pile screenshots are obsolete.
