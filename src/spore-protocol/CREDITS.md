# Artwork provenance

Home artwork and the independent startup explorer were originally generated for Spore Protocol with OpenAI built-in image generation on 2026-10-11, without third-party reference images. The Home canvas preserves the complete field explorer, natural mushrooms and path; launch and empty-state are centered transparent compositions of the separately generated explorer. The earlier specimen pile was removed.

The seven transparent native template glyphs, quiet mode-specific wallpapers, sparse chrome surface marks and split gallery preview are project-authored vector/raster compositions. No font files or external stock artwork are bundled. Final generation prompts are documented in PROMPTS.md.

- `assets/home-composer-compact.png` and `assets/home-composer-regular.png`: original transparent edge artwork generated with OpenAI built-in image generation on 2026-10-12 for this theme; proportionally resized and arranged on transparent phone/Pad canvases. CC-BY-4.0.
- `assets/icon-parameters.png`: existing repository original sliders drawing reused from Pine and Parchment; transparent template rendering, CC-BY-4.0.

- Revised composer assets: independent OpenAI built-in generated original artwork on 2026-10-12, CC-BY-4.0; proportional resizing and transparent layout only.
