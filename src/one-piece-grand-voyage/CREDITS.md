## What this is not

**This is unofficial fan art.** It depicts characters and a ship from *One
Piece*, which is the property of Eiichiro Oda and Shueisha. Generating an image
does not create any right in what the image depicts, so the submitter holds no
rights to the underlying characters and grants none. The `license` field says
the same thing rather than naming a licence, because naming one would claim an
authority over this work that nobody involved has.

Treat it accordingly: it is fine as a personal theme, and it is not a thing to
redistribute commercially, ship inside a product, or present as official.

`assets/home-hero.png`: newly generated with OpenAI image generation for this theme; Luffy standing on a ship bow above curling turquoise waves. Existing franchise notices remain applicable.

## Parameter control update

`assets/icon-parameters.png`: Original Muqun Theme Collection adjustment tracks with open round handles; vector geometry rasterized to a transparent PNG to match this theme’s existing stroke and corner family. The glyph is original geometry under the existing theme license; no third-party character or reference artwork is used in the control. The alpha shape supplies the glyph; native template tint supports both light and dark modes. Settings and parameters remain independent controls.
