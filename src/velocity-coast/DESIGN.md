# Velocity Coast

The current theme uses original adult inline skaters, cobalt surf and warm coral coastal scenery. Genuine transparent full figures sit over subject-free day/night environments. Eight semantic control glyphs and a restrained coastal composer ornament are retained with file-specific provenance in [CREDITS.md](CREDITS.md).

See [DESIGN-REVIEW.md](DESIGN-REVIEW.md) for responsive fitting and validation limits. The prior franchise composition and prompts belong to repository history, not the current design.
