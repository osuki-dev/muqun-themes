# Sulfur and Silence

Iceland's mineral landscape becomes a restrained monotype print: fractured basalt, sulfur shorelines and pale lilac steam. Light mode uses chalk planes and a dark sulfur-olive action color; dark mode uses volcanic charcoal with luminous sulfur-yellow actions and lilac information accents.

Four separate wallpaper compositions support light/dark phone and tablet layouts. Basalt remains at the margins and steam softens the open center. The empty illustration is an isolated basalt-and-pool vignette. Back uses a faceted basalt chevron, send a rising steam arrow, and attachment a crystal-shaped paperclip. All three glyphs use template alpha for mode-correct tinting.

Default Muqun home name and logo are preserved. UI planes use 95% opacity and terminal planes 96%, keeping the illustration subordinate to text. The gallery preview presents light on the left and dark on the right using the theme's own artwork.
