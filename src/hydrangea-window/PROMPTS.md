# Image prompts

All raster artwork was generated with OpenAI image generation and finished for Muqun.

## Background — Light

Create a calm hydrangea window in tsuyu season in a refined editorial illustration style. Use hydrangea blue, lavender, rainy ivory. Wide 2:1 composition, complete scene, no text, no logos, no cropped focal objects.

## Background — Dark

Reimagine the same visual world at night with independently painted lighting, deeper values, preserved detail, and restrained luminous accents. Wide 2:1 composition, no text or logos.

## Hero — Light

Create a transparent hydrangea vase as a complete centered object, transparent background, no cast-off cropping, no words, generous padding, app-icon clarity.

## Hero — Dark

Create a separately lit night variant of a transparent hydrangea vase, transparent background, complete silhouette, no words, generous padding.

The two existing transparent heroes are reused unchanged as the matching Editorial cover foregrounds. No additional generated artwork was needed.
