# Jade Tempest artwork

All character and scenery artwork was newly created for this theme using OpenAI built-in image generation on 2026-09-26. No external artwork or existing franchise character was used. Theme artwork and original geometric icon drawings are distributed under CC0-1.0.

- `home.webp`: original ivory-robed storm summoner with a jade dragon; transparent foreground.
- `launch.webp`: separately generated complete character composition with both boots and spear.
- `wallpaper-light.webp`: monumental mountain kingdom at dawn, without characters.
- `wallpaper-dark.webp`: matching pine-charcoal night setting, without characters.
- `preview.png`: gallery composition assembled from the theme assets.
- `icon-*.png`: original geometric semantic glyph family, drawn for this theme.

Art direction: original anime key visual; jade emerald, bronze and ivory; monumental mountains and wind-driven robes. No baked-in lettering, interface controls, or external marks.
