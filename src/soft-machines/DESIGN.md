# Soft Machines

Pearl resin, mint silicone and smoky lilac glass shape an original soft 2.5D world. Rounded cams and capsule loops are nonfunctional sculptural objects. Broad shadows and frosted refraction add depth while quiet upper fields leave room for actual interface content.

Light mode uses pearl planes with dark green text and mint-family actions; dark mode moves into smoky lilac with pale mint actions. All required UI and ANSI roles are authored independently. Default Muqun name, logo and typography remain intact.

Four dedicated wallpapers support portrait and wide layouts in both modes. The empty-state sculpture uses genuine transparent alpha. Three rounded template glyphs preserve recognizable back, send and attach functions, using the active theme tint. The1024x640 preview shows light on the left and dark on the right.

## Validation

CLI 1.9.0 validation, contrast, package round trip, packaged validation, and the 60-theme source check passed; all 11 assets are present and the theme packs to 418.3 KiB. Shared opacity floors remain 91% for interface and 90% for terminal; authored opacity is 96%. The CLI warns that its published build does not yet read the app's new `homePresentation` field; the field is intentionally retained for the matching app release.

All four wallpapers, both transparent Home compositions, the empty-state sculpture, split cover, and three glyphs were visually inspected. Glyphs were tinted at 17px and 34px on both palettes. The approved browser preview was inspected in both modes: Phone Home, Conversation and Terminal, and Tablet Home and Terminal. No clipping, unreadable text or missing artwork was observed in those gallery renderings. This does not claim a native device import test.

## Home illustration

## Toolbar surfaces

Toolbar controls use the normal theme surface. This theme does not force a transparent or specially translucent toolbar; readers can adjust surface opacity in the app.
