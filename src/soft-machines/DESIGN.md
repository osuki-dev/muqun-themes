# Soft Machines

Pearl resin, mint silicone and smoky lilac glass shape an original soft 2.5D world. Rounded cams and capsule loops are nonfunctional sculptural objects. Broad shadows and frosted refraction add depth while quiet upper fields leave room for actual interface content.

Light mode uses pearl planes with dark green text and mint-family actions; dark mode moves into smoky lilac with pale mint actions. All required UI and ANSI roles are authored independently. Default Muqun name, logo and typography remain intact.

Four dedicated wallpapers support portrait and wide layouts in both modes. The empty-state sculpture uses genuine transparent alpha. Three rounded template glyphs preserve recognizable back, send and attach functions, using the active theme tint. The1024x640 preview shows light on the left and dark on the right.
