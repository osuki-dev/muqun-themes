# Interface Playground

Warm white and cool graphite make room for ultramarine actions and coral alignment details. Three source-authentic frontend marks sit at the perimeter: HTML5, the current CSS logo, and the JSConf JavaScript community mark. Phone layouts keep CSS and JavaScript below the Home cards; tablet layouts redistribute them around the content area. The central reading field stays clear.

Muqun's default name and logo are preserved. Home artwork is full strength; shared artwork is restrained to 22%, with interface planes at 96% and terminal backgrounds at 97%. Original template back, send and attachment glyphs use an angular bracket motif. Technology marks are decorative and do not represent interactive controls.
