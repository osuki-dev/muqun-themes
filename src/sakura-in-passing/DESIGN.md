# Sakura, in Passing

Japan / Himeji, interpreted through cherry-blossom woodblock prints: blush paper, deep crimson and ink indigo. Fine carved contours and softly graded ink make the white keep and passing heron feel like a fleeting spring impression.

Light mode uses blush surfaces and crimson actions; dark mode uses ink-indigo surfaces and pale blossom actions. The wallpaper is composed separately for compact portrait and regular landscape layouts. Interface planes use 92% opacity and terminal planes 94% to preserve reading comfort.

The back glyph suggests a folded fan, the send glyph a heron in flight, and attachment a loop of mizuhiki cord. Template alpha lets each palette supply the tint. The square empty-state vignette is a resting heron and blossom twig; the dedicated gallery cover carries the English title. Default Muqun home identity is retained.

CLI 1.7.1 validation and source checks pass with no warnings for this theme. Contrast floors are 90% interface / 84% terminal in light mode and 89% / 78% in dark mode; authored opacities exceed both. The packed source passes the package round trip. Original artwork, cover title, transparent vignette and glyphs at 17px were inspected locally.
