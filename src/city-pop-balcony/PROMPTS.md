# Image prompts

All raster artwork was generated with OpenAI image generation and finished for Muqun.

## Background — Light

Create a breezy 1980s seaside balcony in a refined editorial illustration style. Use sunset coral, pool aqua, warm ivory. Wide 2:1 composition, complete scene, no text, no logos, no cropped focal objects.

## Background — Dark

Reimagine the same visual world at night with independently painted lighting, deeper values, preserved detail, and restrained luminous accents. Wide 2:1 composition, no text or logos.

## Hero — Light

Create a transparent cassette player with headphones as a complete centered object, transparent background, no cast-off cropping, no words, generous padding, app-icon clarity.

## Hero — Dark

Create a separately lit night variant of a transparent cassette player with headphones, transparent background, complete silhouette, no words, generous padding.
